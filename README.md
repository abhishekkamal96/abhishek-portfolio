# Abhishek Portfolio

This repository contains the source code for my personal portfolio website.

The site is built to present my background as a Senior Software Engineer with experience across backend systems, distributed data platforms, cloud infrastructure, streaming systems, and MLOps. It highlights selected work in areas such as Kafka, Flink, GCP, Terraform, data ingestion frameworks, RAG-based systems, and platform engineering.

## What This Repo Includes

- A single-page portfolio built with React
- Sections for About, Skills, Projects, Experience, Education, and Contact
- Content tailored toward senior backend engineering and data platform roles
- Responsive UI with Tailwind CSS and motion effects using Framer Motion

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- React Icons

## Local Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## Purpose

This repo is intended to serve as the source for my public portfolio and to showcase my engineering experience, technical focus areas, and selected project work.
